# Scan 03 — MIMO Hippocampal Memory Prosthetics (USC / Wake Forest)

**Blueprint claim.** Nonlinear MIMO models decoded and transferred hippocampal memory codes,
boosting human memory scores by 37% and enabling cross-subject memory transmission.

**Verdict: REAL core (37% is accurate); cross-subject *human* transmission OVERSTATED.**

## What the literature actually shows

- **The 37% figure is real.** In a DARPA-funded pilot, a hippocampal MIMO prosthetic
  improved participants' short-term / working-memory performance by **35–37%** over baseline
  (Hampson et al., *J Neural Eng*, 2018).
  [DARPA](https://www.darpa.mil/news/2018/human-memory-prosthesis) ·
  [USC Viterbi](https://viterbischool.usc.edu/news/2018/03/prosthetic-memory-system-successful-in-humans-study-finds/) ·
  [ScienceDaily](https://www.sciencedaily.com/releases/2018/03/180327194350.htm)
- **Specific-memory recall is real.** Wake Forest / USC (2024) reported the first use of a
  neural prosthetic to assist recall of *specific* memories, by writing patterns that mimic
  the hippocampus's own correct encoding.
  [Wake Forest](https://newsroom.wakehealth.edu/news-releases/2024/02/neural-prosthetic-device-can-help-humans-restore-memory)
- **The model class is real.** Sparse large-scale nonlinear dynamical (MIMO / double-Volterra)
  models of human hippocampal spike codes are well documented.
  [PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC5623111/)

## Where the blueprint over-reaches

- **"Cross-subject memory transmission" in humans is not supported.** The human work is
  **within-subject restoration/facilitation**: the prosthetic reads a patient's own CA3
  input code and writes a corrected CA1 output code *in the same person*. Transferring a
  memory code from one *human donor* into a different *human recipient* is **not** what these
  studies show. Donor→recipient code sharing has only been reported at the rodent level and
  under tightly matched conditions, which is a vastly weaker claim than identity transfer.
- The prosthetic operates on **hippocampal input→output transformations** (the encoding
  *operation*), not on storing or moving a person's *semantic/autobiographical identity*.
  It restores the brain's ability to *form* memories; it does not upload a memory.

## Bearing on the blueprint

- **Supports:** that a learned nonlinear model can read and bias hippocampal memory-related
  codes in humans, and that closed-loop write to improve recall is demonstrated.
- **Does NOT support:** the blueprint's leap to cross-*substrate* identity migration. The gap
  between "facilitate this patient's own recall" and "install person A's identity into person
  B's clone" is the central unproven chasm of the whole proposal.
